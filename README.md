# Kubernetes Month – CNCF Jordan 🇯🇴☸️

Welcome to Kubernetes Month, a community-driven learning initiative organized by CNCF Jordan.

This repository contains **slides, labs, and supporting materials** for a structured, beginner-friendly journey into Kubernetes, delivered through weekly sessions.

---

## Program Overview

Kubernetes Month is divided into **weekly sessions**, each focusing on a core Kubernetes domain:

| Week | Topic |
|-----|------|
| Week 1 | Inside a Kubernetes Cluster |
| Week 2 | Kubernetes Networking |
| Week 3 | Observability in Kubernetes |
| Week 4 | Kubernetes from a Business Perspective |
| Week 5 | YAML For Kubernetes |

Each week includes:
- Presentation slides  
- Hands-on labs (where applicable)  
- Supporting explanations and examples  

---

## Labs

Labs are designed to be:
- Beginner-friendly  
- Local-first (Minikube-based)  
- Focused on **understanding concepts**, not just commands  

Typical lab topics include:
- Deployments & Pods
- Services (ClusterIP, NodePort)
- kubectl basics
- Understanding what Kubernetes *does* and *does not* do

---

## Prerequisites for Labs

To follow the labs locally, you will need:

- `kubectl`
- A local Kubernetes cluster:
- Minikube 
- Docker runtime (Docker Desktop, Colima, or equivalent)
